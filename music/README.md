# Music

Audio files in this folder (`.ogg`, `.oga`, `.mp3`, `.m4a`, `.opus`, `.wav`) are bundled with the game and
played as a shuffled background playlist (Settings → Music). Only add music you are free to redistribute:
public-domain recordings (for example performances by US military bands, which are works of the US
government) or Creative Commons tracks, and credit them in `credits.json`:

```json
{
  "Holst_Second_Suite_March.ogg": {
    "title": "Second Suite in F: March (Holst)",
    "credit": "United States Marine Band · public domain"
  }
}
```

Players can also add their own files in Settings → Music; those stay in their browser and are never uploaded.
